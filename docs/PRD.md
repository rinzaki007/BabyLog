# BabyLog 产品需求（第一阶段）

## 定位
供父母共同使用的宝宝日常照护与成长记录工具。先保证记录快速、准确、可追溯，再扩展统计与家庭协作。

## 核心原则
- 离线优先：记录先落本机数据库，不依赖网络。
- 家庭隔离：云端所有宝宝数据按 family_id 隔离，并由 RLS 强制执行。
- 可追溯：事件保留创建者、更新时间、版本和软删除状态。
- 不做医疗诊断：健康记录只用于观察和整理，不能替代专业医疗建议。

## 第一阶段功能
1. 宝宝档案：称呼、出生日期时间。
2. 喂养：亲喂左右侧计时、瓶喂母乳/配方奶 ml、混合喂养。
3. 尿布：小便、大便可分别记录，也可同次记录；大便颜色与性状为可选观察项。
4. 睡眠：开始、结束、时长。
5. 时间轴：按发生时间展示，支持补录、修改、软删除。
6. 家庭同步：父母独立登录，共享同一家庭档案；离线队列和冲突提示。

## 暂不纳入
- 医疗诊断或自动给出用药建议
- 公开分享宝宝档案
- 广告、社交和复杂社区功能
